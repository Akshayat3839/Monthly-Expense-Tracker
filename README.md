# Monthly-Expense-Tracker
Personal Expense Tracker

A Python-based command-line application designed to help users record, manage, and analyze their personal expenses efficiently. The application provides category-wise and monthly spending insights using structured CSV data storage and data visualization.

📌 Features
Add Expenses – Record expenses with details such as date, category, amount, and description.
View Expenses – Display all previously recorded transactions.
Category-wise Analysis – Analyze spending across different expense categories.
Monthly Reports – Generate reports to understand monthly spending patterns.
Data Storage – Store expense records securely in CSV format.
Data Visualization – Generate graphical insights using Matplotlib.
Command-Line Interface – Simple and easy-to-use terminal-based interface.
🛠️ Technologies Used
Python
Pandas – Data processing and analysis
Matplotlib – Data visualization
CSV – Expense data storage
