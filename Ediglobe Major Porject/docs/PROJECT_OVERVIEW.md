# Project Overview

## Title
Personal Expense Tracker — Upgraded

## Purpose
Track daily expenses, store them persistently, generate useful reports, visualize spending, and provide budget/insight features.

## Original internship requirements covered
- Add, view and categorize expenses
- Reports
- CSV storage
- Matplotlib visualization
- Error handling
- Lists/dictionaries
- Functions
- Loops and conditions

## Upgrades
- Edit/delete
- Search/filter
- Budget tracking and alerts
- Smart spending insights
- Text report export

## Future upgrades
- SQLite database
- Login/authentication
- Streamlit/Flask web dashboard
- Machine-learning based expense prediction
- Cloud deployment
