# Personal Expense Tracker — Upgraded

An upgraded Python expense-management project based on the internship PDF requirements.

## Features
- Add, edit and delete expenses
- Categorize expenses
- CSV persistence
- Search/filter by category and date
- Monthly/category-wise reports
- Highest expense and averages
- Budget setting and budget alerts
- Matplotlib charts
- Smart spending insights
- Export a text report
- Input validation and exception handling

## Run
1. Install Python 3.10+.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run:
   `python main.py`

The first run creates `data/expenses.csv` and `data/budget.json`.
